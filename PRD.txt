# Product Requirements Document (PRD)
# Tripsaver Flight + Hotel Offer Automation System

**Version:** 1.0  
**Date:** December 23, 2025  
**Product Owner:** Damian  
**Target Platform:** tripsaver.pl  

---

## 1. Executive Summary

### 1.1 Product Vision
Automate the creation, approval, and publication of flight-only and flight+hotel package offers on tripsaver.pl, reducing manual work while maintaining quality control through strategic approval checkpoints.

### 1.2 Business Goals
- Publish 1 flight+hotel offer daily (minimum)
- Reduce offer creation time from hours to minutes
- Maintain quality through manual approval gates
- Enable scalable growth to multiple daily offers
- Generate revenue through affiliate links (flights) and direct sales (packages)

### 1.3 Success Metrics
- Time to publish: < 15 minutes from approval to live
- Daily offer target: 1+ flight+hotel packages
- User conversion: Track purchase confirmations
- System uptime: 99%+ availability
- Error rate: < 5% failed automations

### 2.1 Primary User: Damian (Admin/Curator)

## 5. Detailed Functional Requirements

### 5.1 Daily Deal Recommendation Engine

#### 5.1.1 CSV Processing
**Input:** `https://raw.githubusercontent.com/PRODG25/tripsaver-data-updater/refs/heads/master/archive/best_deals_detected.csv`

**CSV Schema:**
```
Columns: Outbound From, Destination, ArrivalCountry, Inbound To, 
         Departure Date, Return Date, Trip Duration (Days), 
         Outbound Price, Inbound Price, Total Price, 
         IATA_Departure, IATA_Destination, IATA_Return, 
         Round_Trip_Link, Route, AvgPrice, z_score, 
         price_yesterday, price_change_percent
```

**Processing Logic:**
1. Fetch CSV daily via GitHub Actions (cron: 6:00 AM CET)
2. Parse all rows into structured data
3. Filter valid deals:
   - `Departure Date` >= today + 7 days (minimum advance booking)
   - `Total Price` > 0
   - `z_score` is not null
4. Rank deals by composite score:
   - Primary: `z_score` (lower is better)
   - Secondary: `Total Price` (lower is better)
5. Group by `ArrivalCountry` and select top deals per country
6. Return maximum 20 recommendations total

**Output Format:**
```json
{
  "recommendations": [
    {
      "id": "generated_uuid",
      "route": "Poznań-Mediolan",
      "departure_from": "Poznań",
      "destination": "Mediolan",
      "country": "Włochy",
      "return_to": "Kraków",
      "departure_date": "2026-01-26",
      "return_date": "2026-02-02",
      "duration_days": 7,
      "total_price": 106.0,
      "z_score": -1.67,
      "iata_codes": {
        "departure": "POZ",
        "destination": "MILA",
        "return": "KRK"
      },
      "affiliate_link": "https://skyscanner.net/g/referrals/...",
      "is_multi_ticket": false
    }
  ],
  "generated_at": "2025-12-23T06:00:00Z"
}
```

#### 5.1.2 Notification System
- Send email to admin with:
  - Subject: "🔥 Tripsaver: 20 New Deal Recommendations - [Date]"
  - Body: HTML formatted table with top deals
  - Link to admin UI for approval
- Use Gmail SMTP with app password
- Retry logic: 3 attempts with exponential backoff

#### 5.3.2 Hotel Filtering Logic
**Minimum Requirements:**
- Review score ≥ 6.5
- Review count ≥ 100
- Has photos
- Price available for selected dates

**Ranking Algorithm:**
```python
def calculate_hotel_score(hotel):
    score = 0
    
    # Rating component (40% weight)
    score += (hotel['review_score'] / 10) * 40
    
    # Value component (40% weight)
    price_per_night = hotel['total_price'] / duration_days
    value_score = max(0, (500 - price_per_night) / 500 * 40)
    score += value_score
    
    # Review count component (20% weight)
    review_score = min(hotel['review_count'] / 500, 1.0) * 20
    score += review_score
    
    return score
```

**Return Top 5 Hotels** sorted by score descending.

**JavaScript Logic:**
```javascript
function updatePrice() {
  const count = parseInt(document.getElementById('travelers-count').value);
  let price;
  
  if (count <= 2) price = 49;
  else if (count <= 6) price = 89;
  else price = 129;
  
  document.getElementById('final-price').textContent = price + ' PLN';
}

function confirmPurchase() {
  const email = document.getElementById('customer-email').value;
  const travelers = document.getElementById('travelers-count').value;
  const price = document.getElementById('final-price').textContent;
  const packageId = '[FROM_POST_META]';
  
  // Validate email
  if (!email.match(/^[^\s@]+@[^\s@]+\.[^\s@]+$/)) {
    alert('Proszę podać prawidłowy adres email');
    return;
  }
  
  // Send to backend API
  fetch('/api/orders/create', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      package_id: packageId,
      customer_email: email,
      travelers_count: parseInt(travelers),
      price: parseInt(price),
      timestamp: new Date().toISOString()
    })
  })
  .then(response => response.json())
  .then(data => {
    if (data.success) {
      alert('✅ Zamówienie potwierdzone! Sprawdź email z instrukcjami płatności.');
      closePurchaseModal();
    } else {
      alert('❌ Wystąpił błąd. Spróbuj ponownie lub napisz do nas.');
    }
  })
  .catch(error => {
```

#### 5.5.3 PDF Generation Code (Python Example)

```python
from reportlab.lib.pagesizes import A4
from reportlab.platypus import SimpleDocTemplate, Paragraph, Spacer, Image, Table
from reportlab.lib.styles import getSampleStyleSheet, ParagraphStyle
from reportlab.lib.units import cm
from reportlab.lib import colors
import qrcode

def generate_package_pdf(offer_data, output_path):
    """
    Generate branded PDF for flight+hotel package
    
    Args:
        offer_data: Dict with flight, hotel, pricing info
        output_path: Path to save PDF (GitHub repo path)
    """
    
    doc = SimpleDocTemplate(output_path, pagesize=A4)
    story = []
    styles = getSampleStyleSheet()
    
    # Custom styles with Tripsaver branding
    title_style = ParagraphStyle(
        'CustomTitle',
        parent=styles['Heading1'],
        fontSize=24,
        textColor=colors.HexColor('#FF6B35'),  # Tripsaver orange
        spaceAfter=20
    )
    
    # Page 1: Cover
    logo = Image('tripsaver_logo.png', width=8*cm, height=3*cm)
    story.append(logo)
    story.append(Spacer(1, 2*cm))
    
    title = Paragraph(f"GOTOWY PLAN PODRÓŻY<br/>{offer_data['destination']}", title_style)
    story.append(title)
    
    dates = Paragraph(
        f"{offer_data['departure_date']} - {offer_data['return_date']}<br/>"
        f"{offer_data['duration_days']} dni",
        styles['Normal']
    )
    story.append(dates)
    story.append(Spacer(1, 2*cm))
    
    # Hero image
    if offer_data['hero_image_url']:
        hero_img = Image(offer_data['hero_image_url'], width=15*cm, height=10*cm)
        story.append(hero_img)
    
    # Page 2: Flights
    story.append(PageBreak())
    flights_title = Paragraph("✈️ SZCZEGÓŁY LOTÓW", title_style)
    story.append(flights_title)
    
    for idx, ticket in enumerate(offer_data['tickets'], 1):
        ticket_title = Paragraph(f"LOT #{idx}: {ticket['label']}", styles['Heading2'])
        story.append(ticket_title)
        
        # Flight details table
        flight_data = [
            ['Trasa:', f"{ticket['from_city']} ({ticket['from_iata']}) → {ticket['to_city']} ({ticket['to_iata']})"],
            ['Data wylotu:', ticket['departure_date']],
            ['Data powrotu:', ticket['return_date']],
            ['Cena:', f"{ticket['price']} PLN"]
        ]
        
        flight_table = Table(flight_data, colWidths=[4*cm, 11*cm])
        flight_table.setStyle(TableStyle([
            ('BACKGROUND', (0, 0), (0, -1), colors.lightgrey),
            ('GRID', (0, 0), (-1, -1), 1, colors.black)
        ]))
        story.append(flight_table)
        story.append(Spacer(1, 0.5*cm))
        
        # QR Code for affiliate link
        qr = qrcode.make(ticket['affiliate_link'])
        qr_path = f"/tmp/qr_ticket_{idx}.png"
        qr.save(qr_path)
        qr_img = Image(qr_path, width=3*cm, height=3*cm)
        
        qr_label = Paragraph(f"🔗 SKANUJ ABY KUPIĆ BILET #{idx}", styles['Normal'])
        story.append(qr_label)
        story.append(qr_img)
        story.append(Spacer(1, 1*cm))
    
    # Total flight cost
    total_flights = Paragraph(
        f"💰 ŁĄCZNY KOSZT LOTÓW: {offer_data['total_flight_price']} PLN",
        styles['Heading3']
    )
    story.append(total_flights)
    
    # Page 3: Hotel
    story.append(PageBreak())
    hotel_title = Paragraph("🏨 TWÓJ HOTEL", title_style)
    story.append(hotel_title)
    
    hotel = offer_data['hotel']
    hotel_img = Image(hotel['main_photo_url'], width=15*cm, height=10*cm)
    story.append(hotel_img)
    story.append(Spacer(1, 0.5*cm))
    
    hotel_name = Paragraph(
        f"{hotel['name']} {'⭐' * hotel['stars']}<br/>"
        f"Ocena: {hotel['rating']}/10 ({hotel['review_count']} opinii)",
        styles['Heading2']
    )
    story.append(hotel_name)
    
    hotel_details = [
        ['📍 Adres:', f"{hotel['address']}<br/>{hotel['district']}, {hotel['city']}"],
        ['📅 Termin:', f"Zameldowanie: {hotel['checkin_date']}<br/>Wymeldowanie: {hotel['checkout_date']}"],
        ['🛏️ Pobyt:', f"{hotel['nights']} nocy"],
        ['💰 Koszt:', f"~{hotel['price_per_night']} PLN/noc<br/>~{hotel['total_price']} PLN całość"]
    ]
    
    hotel_table = Table(hotel_details, colWidths=[4*cm, 11*cm])
    hotel_table.setStyle(TableStyle([
        ('BACKGROUND', (0, 0), (0, -1), colors.lightgrey),
        ('GRID', (0, 0), (-1, -1), 1, colors.black),
        ('VALIGN', (0, 0), (-1, -1), 'TOP')
    ]))
    story.append(hotel_table)
    story.append(Spacer(1, 1*cm))
    
    # Amenities
    amenities_title = Paragraph("✅ UDOGODNIENIA:", styles['Heading3'])
    story.append(amenities_title)
    
    amenities_list = "<br/>".join([f"• {am}" for am in hotel['amenities']])
    amenities_p = Paragraph(amenities_list, styles['Normal'])
    story.append(amenities_p)
    story.append(Spacer(1, 1*cm))
    
    # Booking QR
    booking_qr = qrcode.make(hotel['booking_url'])
    booking_qr_path = "/tmp/qr_hotel.png"
    booking_qr.save(booking_qr_path)
    
    booking_label = Paragraph("🔗 ZAREZERWUJ HOTEL (skanuj kod)", styles['Normal'])
    story.append(booking_label)
    
    booking_qr_img = Image(booking_qr_path, width=4*cm, height=4*cm)
    story.append(booking_qr_img)
    
    # Page 4: Practical info (similar structure)
    # ... (add remaining pages)
    
    # Build PDF
    doc.build(story)
    print(f"✅ PDF generated: {output_path}")
```

```python
import subprocess

def upload_pdf_to_github(pdf_path, package_id):
    """Upload generated PDF to GitHub repo"""
    
    year = package_id.split('-')[2][:4]
    month = package_id.split('-')[2][4:6]
    
    github_path = f"packages/{year}/{month}/{package_id}.pdf"
    
    # Git commands
    subprocess.run(['git', 'add', pdf_path])
    subprocess.run(['git', 'commit', '-m', f'Add package PDF: {package_id}'])
    subprocess.run(['git', 'push', 'origin', 'master'])
    
    raw_url = f"https://raw.githubusercontent.com/PRODG25/tripsaver-pdfs/master/{github_path}"
    return raw_url
```

```python
import smtplib
from email.mime.text import MIMEText
from email.mime.multipart import MIMEMultipart

def send_email(to_email, subject, html_body):
    """Send email via Gmail SMTP"""
    
    # Configuration (from env variables)
    SMTP_HOST = 'smtp.gmail.com'
    SMTP_PORT = 587
    SENDER_EMAIL = 'kontakt@tripsaver.pl'  # Your Gmail
    APP_PASSWORD = os.getenv('GMAIL_APP_PASSWORD')
    
    # Create message
    msg = MIMEMultipart('alternative')
    msg['From'] = f"Tripsaver <{SENDER_EMAIL}>"
    msg['To'] = to_email
    msg['Subject'] = subject
    
    # Add HTML body
    html_part = MIMEText(html_body, 'html', 'utf-8')
    msg.attach(html_part)
    
    # Send
    try:
        with smtplib.SMTP(SMTP_HOST, SMTP_PORT) as server:
            server.starttls()
            server.login(SENDER_EMAIL, APP_PASSWORD)
            server.send_message(msg)
        
        print(f"✅ Email sent to {to_email}")
        return True
        
    except Exception as e:
        print(f"❌ Email failed: {str(e)}")
        return False
```
